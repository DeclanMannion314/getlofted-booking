# Get Lofted Property Services Booking App

A simple booking and job tracking tool built for Get Lofted Property Services. Customers send a job request through a form, and every request can be tracked through to completion on a mobile friendly dashboard with a calendar view.

## Live site

- **Booking form**: https://YOUR-SERVICE-NAME.onrender.com
- **Dashboard**: https://YOUR-SERVICE-NAME.onrender.com/dashboard.html

## Features

- Customers submit job requests (name, phone, address, type of work, description, urgency, preferred date)
- Password protected dashboard to view, update and delete jobs
- Job status tracking (New, Contacted, Scheduled, Done)
- Calendar view showing jobs by scheduled date
- Data stored in MongoDB

## Tech stack

Node.js, Express, MongoDB, vanilla HTML/CSS/JavaScript.
